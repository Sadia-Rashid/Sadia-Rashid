# Sadia Rashid — Vercel Portfolio

This is a static, responsive portfolio designed around Sadia Rashid's supplied information.

## Deploy to Vercel
1. Create a Vercel account.
2. Use **Vercel Drop** and upload this folder (or the ZIP contents).
3. Vercel will generate a `.vercel.app` URL.
4. For ongoing editing, connect the project to GitHub.

## Main editable files
- `index.html` — all portfolio text/content
- `style.css` — layout and the yellow/grey/charcoal visual system
- `script.js` — mobile menu behavior

## Important
Project evidence is deliberately marked as "to be added" until actual screenshots/files/links are supplied. No invented clients, results or fake project evidence are included.
